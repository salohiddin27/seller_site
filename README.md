## ℹ️ About the Project

This project is mainly focused on **Python (Django) backend development**, with an emphasis on clean architecture and real-world business logic.

### 🛠 Tech Stack & Features

* **Django ORM** – database modeling and queries
* **Django Rest Framework (DRF)** – RESTful API development
* **Database & model design**
* **Filtering & searching** functionality
* **Shopping cart (basket) logic**
* **Authentication & authorization** (`login_required`)

The project is designed to demonstrate solid backend principles rather than UI complexity.

---

## 🧑‍💻 Frontend

The frontend layer is implemented using:

* **Django Templates (HTML)**
* **Basic CSS**
* **JavaScript (Fetch API)** for async requests

The UI and layout were created with **AI-assisted development** to quickly demonstrate and test backend functionality.

📌 **Note:**
The author of this project is primarily a **backend developer**.
The frontend exists mainly as a **demo layer** to interact with backend APIs and logic.

---

## 🎯 Project Purpose

This project aims to showcase:

* Backend architecture and structure
* REST API behavior and data flow
* Database interaction using Django ORM
* Real-world backend business logic implementation

The frontend can be easily replaced in the future with modern frameworks such as **React**, **Vue**, or **Next.js**.
